# Unidad 1. Introducción a la inteligencia artificial

## Proyecto de investigación: IA e impacto ambiental

Propuesta de un sistema con inteligencia artificial para monitorear la calidad del agua del río Culiacán. Se revisan tres problemas del río (descargas de aguas negras, lirio acuático y especies invasoras), cómo se ha usado la IA en otros ríos y lagos con problemas parecidos, y se propone una solución para el río Culiacán.

Entregado el 17 de septiembre de 2026.
